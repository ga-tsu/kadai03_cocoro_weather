# ①課題名
こころの天気予報

## ②課題内容（どんな作品か）
- 前回提出したエンゲージメントチェックのアプリをベースにアップデートし、自分の今の状態を知り、自分に寄り添うアプリ「ココロの天気予報」を作成した。

- 10問の設問にYes／Noで回答することで、現在の仕事へのエンゲージメントを天気に例えて可視化する。診断結果に応じたアドバイスや、小さな行動を提案するカードを表示する機能に加え、診断結果やその日の気持ちを記録し、自分の変化を振り返ることができる「ココロ日記」を実装した。

## ③アプリのデプロイURL
https://f-tsuga.github.io/kadai02_jyanken_rich.ver/

## ④工夫した点・こだわった点

### 1. アプリのコンセプトの再設計
- エンゲージメントの高低を測定するアプリから、今の自分の状態を知り、自分に寄り添うアプリ「ココロの天気予報。」へ変更。
- 診断するだけではなく、「自分を知る → 自分を受け入れる → 小さな行動を試す → 自分の変化を楽しむ」という一連の体験を設計した。

### 2. UI・UXの改善
- 10問の設問を一覧表示する方式から、1問ずつ表示する方式に変更。回答すると自動的に次の設問に進むようにした。
- 前の設問に戻り、回答を修正できる機能を追加した。
- 柔らかい配色や丸みのあるデザインを採用し、気軽に試してみたいと思える雰囲気を目指した。

### 3. 診断結果の見せ方の工夫
- エンゲージメントの高・中・低という表現を天気に置き換え、診断結果を前向きに受け止められるようにした。

### 4. 診断から行動につなげる仕組み
- 従来のガチャを「今日の、小さな一歩。」という行動カードに変更した。
- 診断結果に応じて抽選対象となるカードを変え、引き直しや行動の選択ができるようにした。

### 5. 継続的な利用を促す仕組み
- 診断結果だけでなく、選択した行動やその日の気持ちをメモとして保存できる「ココロ日記」を実装した。
- 過去の診断結果を一覧表示するとともに、過去の結果をグラフ化し、自分の変化を視覚的に振り返れるようにした。
- localStorageを活用し、ブラウザを閉じても記録が残るようにした。

## ⑤難しかった点・次回トライしたいこと（又は機能）
- ココロ日記のメモ欄に前回入力した文字が残ってしまう不具合が発生した。JavaScriptで入力欄を初期化する処理を追加したが、解消されなかった。
- 原因を探る過程で、自分が書いたコードだけでなく、ブラウザによる入力内容の復元やキャッシュなども、アプリの動作に影響する可能性があることを学んだ。
- 今後は、不具合が発生した際に、単にコードを修正するだけではなく、なぜ意図した通りに動かないのか、原因の仮説を立て、検証する力（デバッグ力）も身につけていきたい。
